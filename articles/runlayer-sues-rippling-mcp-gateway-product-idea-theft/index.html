MCP Startup Sues HR Unicorn
Big Tech 'Reference' Playbook Returns in AI Era

MCP网关创业公司Runlayer起诉HR巨头Rippling剽窃产品创意——评估完转头自己做，老套路在AI协议时代披新皮。

MCP gateway startup Runlayer sues HR giant Rippling for stealing its product idea — evaluating then building your own is an old playbook wearing an AI protocol costume.

No.024 2026.07.29 约 4 分钟阅读 ~4 min read

朋友们，今天的AI圈翻车故事，可以写进《创业公司被大厂"借鉴"大全》经典案例一章。

主角叫Runlayer，做MCP（Model Context Protocol）网关的创业公司。MCP是AI Agent时代的"USB接口"——让不同AI模型和工具能互相连接调用的协议标准。Runlayer做企业MCP网关，管理AI工具接入、权限、监控、审计——AI时代的API网关。

"反派"叫Rippling，HR SaaS超级独角兽，估值超百亿美元，美国科技圈和Stripe、Notion齐名的明星公司。

老套剧情，熟悉味道

剧情（根据Runlayer诉状和TechCrunch报道）：Rippling找到Runlayer说你们MCP网关不错，我们在评估企业AI工具栈，想深入了解功能、架构、API设计。有大客户主动上门创业公司当然高兴，Runlayer配合做了演示、回答技术细节、提供产品文档。

然后经典桥段来了——评估结束后Rippling说"感谢分享再考虑考虑"，转头自己组团队做MCP网关。据Runlayer说法，Rippling后来发布的内部MCP网关在功能设计、架构思路、甚至API命名上都和Runlayer产品高度相似。Runlayer怒而起诉，指控剽窃创意、违反保密协议、不正当竞争。

这套路太熟悉了：大公司"评估"创业公司→拿到底层设计→自己"自研"→用体量和渠道碾压。SaaS、云计算、移动互联网时代演过无数遍，这次披了"MCP协议""AI网关"新皮。

最讽刺的是：MCP是Anthropic开源的开放标准，初衷是让AI生态更开放互联。结果围绕开放协议做产品的创业公司，反而被大厂用老套路抄了。好比大家一起修了开放高速公路，有人在路边开收费站，巨头看见直接在旁边也建一个——路是公共的，收费站创意被"参考"了。

"创业公司给大厂做产品演示，就像小羊给狼展示自己的肉质有多鲜嫩。区别在于，至少狼吃完你会承认你好吃。"—— Hacker News热评

给AI创业者三个提醒

案子还在走法律程序，Rippling未正式回应，谁对谁错法院判。但Dawn Vision编辑部给AI生态创业者提三个醒：

第一，NDA该签就签，但别迷信NDA。签了NDA不代表安全，知识产权官司耗时耗力耗钱创业公司拖不起。演示时核心技术秘密和差异化实现细节能不说就不说。

第二，"做平台"和"被平台做"是两种命运。做MCP网关、Agent编排、模型路由这类平台型基础设施，要想清楚护城河是什么。功能创新大公司分分钟抄走；真正护城河是社区生态、数据飞轮、网络效应——抄不走的。

第三，开源是盾也是矛。Runlayer如果当初核心产品开源了，Rippling"自研"就不敢这么明目张胆——开源社区盯着，抄开源代码要遵守许可证。开源不是放弃商业价值，是建立一层保护。

AI协议时代来了，新技术范式带来新创业机会，但大厂"借鉴"创业公司的老套路半毛钱没变。

今天就槽到这里，明天继续。

Friends, today's AI facepalm story belongs in the "big companies 'borrowing' startup ideas" hall of fame.

The protagonist is Runlayer, a startup building an MCP (Model Context Protocol) gateway. MCP is the "USB port" of the AI Agent era — a protocol standard letting AI models and tools connect and call each other. Runlayer builds enterprise MCP gateways managing AI tool access, permissions, monitoring, auditing — the API gateway of the AI era.

The alleged villain is Rippling, HR SaaS super-unicorn valued over $10B, a star company in U.S. tech circles alongside Stripe and Notion.

An Old Script With a Familiar Smell

The plot (per Runlayer's complaint and TechCrunch): Rippling reached out saying their MCP gateway looked interesting, they were evaluating enterprise AI tool stacks, and wanted a deep dive into features, architecture, even API designs. A big customer knocking is exciting for a startup; Runlayer cooperated with demos, answered technical questions in depth, provided documentation.

Then the classic move — after evaluation Rippling said "thanks, we'll think about it," turned around and assembled a team to build their own MCP gateway. According to Runlayer, Rippling's internal MCP gateway bore striking similarities in feature design, architecture, even API naming. Runlayer sued for alleged idea theft, NDA violations, unfair competition.

The script is painfully familiar: big company "evaluates" startup → gets design → builds "in-house" → crushes startup with distribution. It played out in SaaS, cloud, mobile internet countless times — now wearing an "MCP protocol" "AI gateway" costume.

The irony? MCP was open-sourced by Anthropic to make AI more open and interconnected. Yet a startup building on an open protocol gets its ideas "referenced" by a big company using the same old playbook. Like everyone building a public highway, someone opens a toll booth, and a giant builds one right next to it — the road is public, but the toll booth design gets "referenced."

"A startup demoing to a big company is like a lamb showing a wolf how tender its meat is. The difference: at least the wolf admits you taste good after eating you."—— Hacker News comment

Three Reminders for AI Founders

The case is in courts; Rippling hasn't formally responded. But the Dawn Vision editorial desk has three reminders for AI ecosystem founders:

First, sign that NDA — but don't worship it. A signed NDA isn't safety; IP litigation takes years and money startups can't afford. Hold back core trade secrets and differentiated implementation details during demos.

Second, "building a platform" and "getting platformed" are different fates. If you're building platform infrastructure (MCP gateways, agent orchestration, model routing), figure out your real moat. Feature-level innovation gets copied overnight; real moats are community, data flywheels, network effects — things that can't be copied.

Third, open source is both shield and spear. If Runlayer had open-sourced its core product, Rippling might not have dared copy so brazenly — the open-source community watches, and copying open-source code requires license compliance. Open source isn't abandoning commerce; it's adding a layer of protection.

The AI protocol era is here. New paradigms bring new startup opportunities, but big companies' old "borrowing" playbook hasn't changed one bit.

That's all the cao for today. See you tomorrow.
