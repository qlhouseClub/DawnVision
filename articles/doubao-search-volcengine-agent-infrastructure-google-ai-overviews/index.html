7月28日，火山引擎正式上线豆包搜索服务——不是豆包APP搜索升级，是把搜索能力单独拆出，通过API、MCP、Skill开放给所有企业和开发者的Agent。

豆包搜索走出豆包：搜索变Agent水电煤

Agent必须联网搜索是共识，但"能搜索"和"搜完Agent能直接用"之间有工程鸿沟。传统搜索API返回网页链接和标题，Agent还要自己打开网页、解析HTML、提取正文、过滤广告——慢、浪费token、经常出错。像让助理查资料只给抱回一摞书说"自己翻"。

豆包搜索返回结构化、Agent可直接消费的信息：信源名称、权威分级、发布时间、围绕问题的正文摘要、可直接引用的原文Markdown。Agent直接判断够不够新、可不可靠、能不能支撑结论，不用自己解析网页。同时支持API、MCP Server、Skill三种接入——MCP可在Claude Desktop/Cursor/Windsurf直接用，Skill可在Claw类框架一条命令安装。每月500次免费额度。

"AI搜索C端战争只是前菜。真正战场在B端——谁成为所有Agent默认调用的搜索层，谁就是Agent时代的Google。"—— Dawn Vision编辑部

Google 43%和搜索入口重构

43%意味着每天超36亿次搜索用户看到AI摘要而非10个蓝色链接。用户行为从"搜关键词→点链接→自己找答案"迁移为"搜问题→看AI总结→有疑问再点来源"。AI Overviews不是加摘要，是重新定义搜索结果长什么样。

对内容创作者和SEO冲击地震级：以前拼"链接排第一页"，以后拼"被AI引用"——AI摘要不引用你，用户根本不点进来。艾瑞数据显示超78%企业品牌内容首次曝光来自AI搜索引用。豆包搜索做"权威分级"正是因为Agent优先引用权威来源。

两条新闻放一起看：AI搜索不再是C端产品类别，正成为整个AI生态的基础设施层——Agent需要搜索、大模型需要搜索、AI应用需要搜索。搜索不再是目的地，是路径。火山引擎急着开放豆包搜索，正是要先占Agent搜索入口。搜索的AI原生重构，比大多数人想象的快得多。

A year ago, AI search debates compared Perplexity, SearchGPT, Doubao, MetaSo consumer experiences. But two late-July news items pulled the war into a different dimension.

On July 28, Volcengine officially launched Doubao Search Service — not an upgrade to search in the Doubao app, but spinning out search capability as a standalone service, opening it to all enterprise and developer agents via API, MCP, and Skill.

Earlier, TechCrunch reported Google's AI Overviews now appears in 43% of searches — AI-generated answers are rapidly becoming the default way people access information.

Doubao Search Exits the App: Search Becomes Agent Utility

That agents need web search is consensus, but between "can search" and "results agents can directly use" lies an engineering chasm. Traditional search APIs return links and titles; agents still need to open pages, parse HTML, extract bodies, filter ads — slow, token-wasteful, error-prone. Like asking an assistant to research something and getting back a stack of books with "flip through yourself."

Doubao Search returns structured, agent-consumable information: source name, authority rating, publish time, query-focused summaries, citable Markdown excerpts. Agents directly judge freshness, reliability, and evidential support without parsing pages. It supports API, MCP Server, and Skill — MCP works directly in Claude Desktop/Cursor/Windsurf; Skill enables one-command install in Claw-class frameworks. 500 free searches per month.

"Consumer AI search was the appetizer. The real battle is B2B — whoever becomes the default search layer for all agents is the Google of the Agent era."—— The Dawn Vision Editorial Desk

Google's 43% and Restructuring Search Entry

43% means over 3.6 billion searches per day show users AI summaries instead of 10 blue links. User behavior is migrating from "keywords → click links → find answers yourself" to "ask questions → read AI summary → click sources if skeptical." AI Overviews isn't adding a summary — it's redefining what search results look like.

The SEO impact is seismic: it used to be "rank on page one"; going forward it's "get cited by the AI" — if the AI doesn't cite you, users may never click through. iResearch shows over 78% of enterprise brand content first exposure now comes from AI search citations. Doubao Search's "authority grading" exists precisely because agents prioritize citing authoritative sources.

Putting both stories together: AI search is no longer a consumer product category but becoming infrastructure for the entire AI ecosystem — agents need search, foundation models need search, AI apps need search. Search is no longer a destination, it's a path. Volcengine rushed to open Doubao Search precisely to capture agent search entry first. The AI-native restructuring of search is happening faster than most realize.
