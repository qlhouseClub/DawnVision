Meta Muse Code Opens Beta
Multi-Agent Parallel, Price Slayer Enters

Meta发布终端AI编程Agent Muse Code，可并行启动子Agent在独立工作树中同时开发多个功能，成本约为竞品的40%。

Meta releases terminal AI coding agent Muse Code that can spin up sub-agents to build multiple features in parallel in isolated worktrees, at roughly 40% of competitors' cost.

No.031 2026.08.07 约 4 分钟阅读 ~4 min read

AI编程Agent赛道，又进来一个重量级选手。

8月5日，Meta正式发布Muse Code——一个终端AI编程Agent，目前开放Beta测试。一条命令就能安装，可以处理大型代码仓库中的完整软件工程任务：规划改动、写代码、验证结果，全套流程自动化。

这款产品的技术特点很有意思：多Agent并行。当任务足够大时，Muse Code会自动拆分子任务，启动多个子Agent在独立的工作树（worktree）中并行工作，互不干扰，你的工作副本完全不会被碰到。Zuckerberg亲自站台说：测试中我们让它同时为一个游戏构建了6个功能，没有任何冲突。

驱动Muse Code的是Meta此前发布的编程模型Muse Spark。而领导这个产品的人，是今年刚刚加入Meta的Alexandr Wang——Scale AI的前CEO，现在是Meta超级智能实验室的负责人。

价格屠夫入场

Meta切入AI编程赛道的姿势，和它切入其他AI赛道一样：用价格开路。

目前AI编程Agent的头部玩家是OpenAI Codex和Anthropic Claude Code。以Claude Code Sonnet为例，输入价格约为3美元/百万token。而Muse Code的输入价格是1.25美元/百万token——差不多是Claude Code Sonnet的42%。

接近一半的价格，功能上却没有明显缩水。Alexandr Wang在接受华尔街日报采访时的说法很直白："我们认为，对于很多工作流和使用场景来说，这会是一个非常好的选择，尤其是从成本角度考虑。"

翻译一下就是：我们便宜，而且够用。对于很多中小团队和个人开发者来说，够用+便宜就是硬道理。

这招Meta在开源大模型上已经验证过了。Llama系列靠开源+免费+性能接近闭源模型，迅速占据了大模型开源生态的头把交椅。现在它想用同样的打法打AI编程市场：性能不比你差多少，但价格只有你的一半，你怎么跟我打？

AI编程的价格战开打了

Muse Code的发布标志着一件事：AI编程工具的价格战正式打响了。

过去一年，AI编程助手从Copilot单代模式进化到了Agent全流程模式。Codex、Claude Code、Cursor、Devin、Windsurf……产品越来越多，能力越来越强，但价格也水涨船高。顶级编程Agent的月费动辄几十上百美元，对于个人开发者和小团队来说并不便宜。

Meta进来之后，这个局面会被打破。它有算力、有模型、有开源生态，打价格战没人打得过它。更重要的是，Meta做AI编程Agent不是为了靠这个赚钱——它是为了构建生态、吸引开发者、完善它的AI工具链。只要能把开发者留在Meta的AI生态里，Muse Code哪怕不赚钱也没关系。

对于开发者来说，这当然是好事。选择变多了，价格变低了，工具变强了。但对于其他AI编程创业公司来说，压力就大了——当Meta把价格打到这个位置，你要么降价（利润更薄），要么做差异化（难度很大），要么等死。

AI编程是AI落地最快、付费意愿最强的赛道之一。但随着巨头入场，这个赛道的创业窗口正在快速关闭。未来能活下来的AI编程公司，要么有极强的产品体验和用户粘性，要么有不可替代的垂直能力——否则在巨头的价格攻势面前，真的很难扛。

明天见。

The AI coding agent track just got another heavyweight entrant.

On August 5, Meta officially launched Muse Code — a terminal AI coding agent currently in public beta. Installable with a single command, it handles complete software engineering tasks across large code repositories: planning changes, writing code, validating results — the entire workflow automated.

The product's technical signature is interesting: multi-agent parallelism. When a task is big enough, Muse Code automatically splits it into subtasks and spins up multiple sub-agents working in parallel in isolated worktrees. They don't interfere with each other, and your working copy is never touched. Zuckerberg personally endorsed it: in testing, we had it build six features for a game simultaneously with zero collisions.

Powering Muse Code is Muse Spark, Meta's previously released coding model. And leading the product is Alexandr Wang — the former CEO of Scale AI, who joined Meta earlier this year and now heads Meta Superintelligence Labs.

The Price Slayer Enters

Meta's approach to entering the AI coding race is the same as its approach to every other AI race: lead with price.

Currently the top players in AI coding agents are OpenAI Codex and Anthropic Claude Code. Take Claude Code Sonnet, for example: input pricing is roughly $3 per million tokens. Muse Code's input pricing is $1.25 per million tokens — roughly 42% of Claude Code Sonnet's price.

Near half the price, without a significant drop in capability. Alexandr Wang put it bluntly in a Wall Street Journal interview: "We think that for a lot of workflows and a lot of use cases, this can be an incredibly good option, especially from a cost perspective."

Translation: we're cheap, and we're good enough. For many small teams and individual developers, good enough + cheap is all that matters.

Meta already validated this playbook with open-source LLMs. The Llama series, backed by open source + free + performance approaching closed-source models, quickly took the top spot in the open-source LLM ecosystem. Now it wants to use the same strategy on the AI coding market: performance isn't that far behind, but the price is half — how do you compete with that?

The AI Coding Price War Has Officially Begun

The release of Muse Code marks one thing: the AI coding tool price war has officially started.

Over the past year, AI coding assistants have evolved from the Copilot generation-suggestion model to full agent-based workflows. Codex, Claude Code, Cursor, Devin, Windsurf… more and more products, stronger and stronger capabilities, but prices have also gone up. Top-tier coding agents cost tens or hundreds of dollars a month, which isn't cheap for individual developers and small teams.

With Meta entering the picture, this dynamic gets disrupted. It has compute, models, and an open-source ecosystem — nobody can beat it on price. More importantly, Meta isn't building AI coding agents to make money from them — it's building ecosystem, attracting developers, and completing its AI toolchain. As long as it keeps developers in Meta's AI ecosystem, it doesn't matter if Muse Code doesn't turn a profit on its own.

For developers, this is obviously great news. More choices, lower prices, better tools. But for other AI coding startups, the pressure just got real — when Meta drives prices down to this level, you either cut prices (thinner margins), differentiate (very hard), or die.

AI coding is one of the fastest-adopting and highest-willingness-to-pay sectors in AI. But with giants entering the ring, the startup window for this track is closing fast. The AI coding companies that survive will either have exceptional product experience and user stickiness, or irreplaceable vertical capabilities — otherwise, facing the giants' price offensive, it's really hard to hold on.
