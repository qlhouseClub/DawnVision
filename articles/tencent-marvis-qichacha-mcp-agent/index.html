查公司，不用再打开企查查了。

8月17日消息，腾讯操作系统层级的个人AI助手Marvis正式接入了企查查MCP服务。以后你在跟Marvis对话的时候，只要提到一个公司的名字，它就会自动调用企查查的服务，返回工商信息、股东结构、主要人员、风险信息等你需要的数据——不需要切换App，不需要复制粘贴，就在对话里完成。

这个更新看起来不起眼，但它是一个非常重要的信号：MCP（Model Context Protocol）正在从开发者的专业工具，变成普通用户日常使用的能力。

为什么MCP接入很重要？

先解释一下MCP是什么。简单说，MCP是一个让AI能调用外部工具和数据的开放协议——AI可以通过MCP查天气、订机票、发邮件、查数据库、调用各种服务，就像人类使用各种App一样。

过去几个月，MCP在开发者圈子里已经非常火了——成千上万的MCP服务被开发出来，从查GitHub到发推特，从操控智能家居到分析股票，几乎你能想到的服务都有对应的MCP。但这些MCP服务主要还是开发者在用，普通用户感知不强——因为你需要自己配置、自己接入、自己管理，有一定的技术门槛。

腾讯Marvis这次接入企查查MCP的意义在于：它是操作系统级别的AI助手，而且是由官方预先集成好常用的MCP服务。你不需要懂什么是MCP，不需要配置任何东西，只需要用自然语言说"帮我查一下某某公司的信息"，它就自动帮你调用了。

这才是MCP真正普及的路径——不是让每个用户自己去配置，而是像手机预装App一样，由操作系统和AI助手厂商把常用的服务预先接好，用户开箱即用。

操作系统级Agent时代开始了

腾讯做Marvis的思路很清晰：不是做一个聊天App，是做操作系统层级的AI助手——它活在你的系统里，随时可以召唤，可以调用你系统里的所有功能，可以接入互联网上的各种服务，帮你完成各种任务。

这次接入企查查只是一个开始。可以预见，接下来会有更多的MCP服务被接入：查快递、点外卖、订酒店、买机票、预约医生、处理文档、管理日程……当所有常用服务都通过MCP接入到系统级AI助手之后，我们使用电脑和手机的方式会发生根本性的变化——你不需要在几十个App之间跳来跳去，大部分事情都可以在对话里完成。

这才是AI Agent真正走进普通人生活的方式。不是靠一个什么万能的聊天机器人，而是靠操作系统深度集成+MCP生态+自然语言交互，让AI真正成为你和数字世界之间的中间层。

微信的接入、支付宝的接入、各种第三方服务的接入——当这张网越织越大的时候，Agent就不再是"一个功能"，而是你使用整个数字世界的主要入口。

To look up a company, you no longer need to open Qichacha.

News on August 17: Tencent's OS-level personal AI assistant Marvis officially integrated Qichacha's MCP service. Now when you mention a company name in conversation with Marvis, it automatically calls Qichacha's service to return business registration info, shareholder structure, key personnel, risk data—whatever you need. No app switching, no copy-pasting—it all happens in the conversation.

This update looks minor, but it's a very important signal: MCP (Model Context Protocol) is moving from a specialized developer tool into an everyday capability for regular users.

Why MCP Integration Matters

First, a quick explanation of MCP. Simply put, MCP is an open protocol that lets AI call external tools and data sources—AI can use MCP to check weather, book flights, send emails, query databases, and invoke all kinds of services, just like a human using apps.

Over the past few months, MCP has exploded in developer circles—thousands of MCP services have been built, from checking GitHub to posting to social media, from controlling smart homes to analyzing stocks. Almost any service you can think of has an MCP. But these MCP services were mainly used by developers; regular users didn't feel them much—because you had to configure, integrate, and manage them yourself, with a certain technical barrier.

The significance of Tencent Marvis integrating Qichacha MCP is: it's an OS-level AI assistant, with commonly used MCP services pre-integrated officially. You don't need to know what MCP is, you don't need to configure anything—just say in natural language "look up information about X company," and it calls it for you automatically.

That's the real path to MCP mass adoption—not having every user configure things themselves, but having the OS and AI assistant vendors pre-integrate commonly used services like pre-installed apps on a phone. It just works out of the box.

The Era of OS-Level Agents Begins

Tencent's vision for Marvis is clear: it's not building a chat app—it's building an OS-level AI assistant that lives in your system, summonable at any time, that can call all your system's functions, connect to services across the internet, and get things done for you.

Qichacha integration is just the beginning. Predictably, more MCP services will be integrated next: package tracking, food delivery, hotel booking, flight reservation, doctor appointments, document processing, schedule management... When every commonly used service is connected to the system-level AI assistant via MCP, the way we use computers and phones will change fundamentally—you won't jump between dozens of apps; most things can be done in conversation.

That's how AI agents truly enter ordinary people's lives—not via some omnipotent chatbot, but via deep OS integration plus the MCP ecosystem plus natural language interaction, making AI the middle layer between you and the digital world.

WeChat integration, Alipay integration, all kinds of third-party service integration—as this web weaves tighter and tighter, agents stop being "a feature" and become your primary interface to the entire digital world.

Marvis integrating Qichacha MCP is a small step, but it's a big leap for mainstream adoption of OS-level agents.
